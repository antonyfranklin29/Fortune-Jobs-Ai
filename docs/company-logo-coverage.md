# Company logo coverage

The job catalogue usually contains an employer name without an employer domain or logo. A name alone can refer to several organizations. The website displays local verified marks, source-provided marks, and exact company matches from Logo.dev. It keeps the initial when identity is ambiguous or a mark is unavailable; it never substitutes a guessed logo.

Logo.dev images send only the site origin as their referrer, so a publishable key can be restricted to `fortunejobsai.com` without sharing a search URL or user details. All other page requests keep the site's `no-referrer` policy.

`scripts/sync-company-logos.mjs` reads distinct open employers from the public Supabase catalogue and looks up new names with Logo.dev's server-side Search API. Automatic matches require both the top result's exact company name (ignoring legal suffixes and punctuation) and a matching primary domain label. Aliases and ambiguous names need manual verification against an employer-owned website or careers page. It writes public, non-secret results to `data/company-logo-resolution.json` and `company-brand-map.js`, with candidate domains for unresolved names. Unmatched names are retried after 30 days. Matched names use Logo.dev's domain-specific CDN URL with a 404 fallback, so missing artwork shows the site's honest initial instead of a provider-generated mark. The website links to Logo.dev in its public footers to satisfy the free plan's attribution requirement. The workflow requests a GitHub Pages rebuild when the map changes, because a bot-authored commit alone does not trigger one.

The 2026-10-28 audit found 2,545 open jobs from 1,111 companies. After checking high-volume employers against their own websites or career pages, 1,869 jobs from 641 companies resolve to a mapped logo. The remaining listings retain an initial until their employer identity and artwork can be confirmed. Re-audit coverage as the catalogue changes; a logo alone is not verification that the job posting is authentic.

To activate automatic refresh, create a Logo.dev account and add two GitHub Actions secrets to this repository: `LOGO_DEV_SECRET_KEY` and `LOGO_DEV_PUBLISHABLE_KEY`. The public Supabase key is already in `config.js`. Do not put the Logo.dev secret key in a web page, a commit, or chat. Run the **Refresh company logos** workflow once; it then refreshes daily. The workflow safely does nothing until configured. Inspect `data/company-logo-resolution.json` for `review` entries and correct any mistaken identity before promoting a candidate. Third-party matching cannot promise that every employer will have a verified logo; small or ambiguous companies will retain an initial until their official domain is confirmed.
