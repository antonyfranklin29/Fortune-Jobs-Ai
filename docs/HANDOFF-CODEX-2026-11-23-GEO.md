# Codex brief — Nov 23 2026: GEO answer blocks, FAQs and category hub pages

Why: a GEO audit (Nov 23) found our public job pages list jobs but give AI tools (ChatGPT, Perplexity, Google AI Overviews) nothing quotable. Perplexity mentioned fortunejobsai.com for 1 of 6 test questions (only "what is Fortune Jobs AI"). Home/About now have crawler-readable text and an FAQ (done by Claude); this brief covers the generated job pages.

One branch `codex/geo-job-pages`, one PR. No merge, deploy, migration or cron change. `npm test` has 32 known failures on main; add none.

## 1. Answer block on every indexed role/state and role/city page
Generated by `scripts/build-job-seo.mjs`, from the same rows the page already lists (never invented):
- Directly under the H1, one 40–80 word paragraph, e.g.: "Fortune Jobs AI lists 34 open Registered Nurse jobs in Arizona, updated November 23, 2026. Listed pay ranges from $38 to $52 an hour where employers show pay. Top hiring employers: Banner Health, HonorHealth and Dignity Health. 12 listings mention entry-level or new-grad roles. Every listing links to the original posting."
- Pay: use only listings with a parsed salary; show the 25th–75th percentile, hourly for hourly roles and yearly otherwise. Omit the sentence when fewer than 5 listings show pay.
- Top employers: up to 3 by count (never "Jobg8"; use the advertiser name).
- Entry-level count: titles or descriptions matching entry level / new grad / junior / graduate / no experience. Omit when 0.
- Remote count for tech roles when > 0. Visa/OPT count (existing `sponsorship` field) when > 0.
- A visible "Updated <Month D, YYYY>" line.

## 2. FAQ on every indexed page (3–5 questions)
Visible `<h2>Frequently asked questions</h2>` followed by `<h3>` question / `<p>` answer pairs, built from the same data. Only include a question when the data supports an answer:
- How many <Role> jobs are open in <Place>? (count + date)
- How much do <Role> jobs in <Place> pay? (the range above + "where employers list pay")
- Which employers are hiring <Role>s in <Place>? (top 3–5)
- Are there entry-level <Role> jobs in <Place>? (count)
- Do any <Role> jobs in <Place> mention visa sponsorship or OPT? (count; "confirm with the employer")
- Healthcare roles only: "Do I need a license?" — RN: an active RN license for the state or a multistate (NLC) license; LPN/LVN: state LPN/LVN license; CNA: state CNA certification. Transport: CDL-A or CDL-B as stated in the listings. Keep these generic and true; no state-specific legal claims.
Add `FAQPage` JSON-LD that mirrors the visible FAQ exactly (same questions and answer text). **No JobPosting markup.**

## 3. Category hub pages
- `/jobs/healthcare/`, `/jobs/tech/`, `/jobs/transport/` (generate a hub only when it has ≥ 25 open jobs; transport will be skipped for now).
- Each: H1, 60–100 word answer (total open jobs, roles covered, top states, updated date), a table of role × top states linking to existing indexed pages, and a 3–5 question FAQ + FAQPage JSON-LD.
- Add hubs to `sitemap.xml` and link them from `/jobs/` and from the homepage tiles' target if simple.

## 4. Freshness and sitemap
- Each generated page's sitemap `<lastmod>` = the generation date.
- Keep thin city pages `noindex` and out of the sitemap, as today.

## Rules
- "Job portal" wording; never "straight from employers" or "skip the middleman"; no fake reviews or ratings.
- Numbers only from the catalogue rows; round nothing up.
- Never display "Jobg8"; don't alter WhatJobs text or links.
- Tests: answer/FAQ generation with and without pay data, percentile maths, FAQ JSON-LD equals visible FAQ, no JobPosting, hub threshold, sitemap lastmod.
